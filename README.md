# Pokédex

Uma Pokédex interativa desenvolvida com HTML, CSS e JavaScript, utilizando a [PokéAPI](https://pokeapi.co/) para obter informações sobre os Pokémon da região de Kanto.

O projeto permite explorar os 151 Pokémon da primeira geração, consultar suas características e visualizar informações detalhadas em uma interface interativa.

## Funcionalidades

- **Listagem de Pokémon:** exibição dos 151 Pokémon da região de Kanto.
- **Busca:** pesquisa por nome ou número do Pokémon.
- **Filtro por tipo:** permite filtrar Pokémon de acordo com seu tipo.
- **Detalhes do Pokémon:** visualização de informações como altura, peso, experiência base e geração.
- **Habilidades:** exibição das habilidades de cada Pokémon.
- **Estatísticas:** apresentação dos atributos de batalha, como HP, ataque, defesa e velocidade.
- **Navegação:** possibilidade de navegar entre os Pokémon através dos botões anterior e próximo.
- **Descrições:** consulta das descrições dos Pokémon através da PokéAPI.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- PokéAPI

## API utilizada

Os dados são obtidos através da [PokéAPI](https://pokeapi.co/), uma API pública que disponibiliza informações sobre Pokémon, incluindo imagens, tipos, habilidades, estatísticas e descrições.

## Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/hiaguin-dev/Pokedex.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Pokedex
   ```

3. Abra o arquivo `index.html` no navegador.

**Observação:** é necessária uma conexão com a internet para carregar os dados da PokéAPI.
